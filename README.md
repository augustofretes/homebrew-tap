# Homebrew Tap

Homebrew formulae for [@augustofretes](https://github.com/augustofretes)'s projects.

## Usage

```bash
brew install augustofretes/tap/rusty-tube
```

## Formulae

- **[rusty-tube](https://github.com/augustofretes/rusty-tube)** — a terminal-based YouTube Music player written in Rust.
